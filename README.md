# maskara releases

builds of the maskara app for macOS: share your screen without leaking it. everything but the app you present is blurred, and personal data inside it is boxed out before a frame leaves your Mac. built on [maskara-ai](https://github.com/maskaradev/maskara-ai).

**install:** download the latest `maskara-x.y.z.dmg` from [releases](https://github.com/maskaradev/maskara-releases/releases/latest), open it and drag maskara to Applications. it updates itself from then on.

macOS 14 or later on Apple silicon. signed with Developer ID and notarized by Apple.

this repository only holds builds and `appcast.xml`, the update feed the app checks. it is written by the release pipeline; don't edit it by hand.
